# Web 离线数据处理

数据处理把完整采集数据转换为需要的训练输入。全局选择仅作用于 `observation.state`，应用于本次导出的全部回合；动作、各视角视频、任务描述和逐帧标注保留。剔除以整条 episode 为单位，不删除中间帧，也不拼接不连续轨迹。

## 环境与支持格式

使用 `vla` Python 3.12 环境，按 `requirements-web.lock` 安装 Web 依赖，再安装本项目。新增的离线组件使用 pandas 2.3.3、PyArrow 26.0.0、PyAV 15.1.0；预览不加载模型，也不启动 ROS 或设备。

首版支持 VLA 的 LeRobot v3 数据：每回合独立 parquet、每个视角独立 MP4、视频从零开始，状态字段具名。支持旧 29D/31D/58D、新 50D/100D 及此页面生成的字段子集。共享 parquet／视频的压缩布局、内嵌图片及其他外部格式会明确拒绝；不在浏览时隐式迁移数据。

转换要求来源明确声明动作按 absolute 存储。输出使用绝对动作统计；训练统计须在划分后用 `vla-action-contract` 按实际 chunk 采样规则生成。页面支持关节／TCP 导出和 absolute／chunk_relative 预览；跨空间导出须显式确认派生来源。所选维度仍需与训练配置一致；提取不会自动让任意维度适配现有 PI0.5 模型。LeRobot 0.6.1 对 shape=[1] 数值特征返回标量，单维输出遵循其存储约定。

## 使用流程

1. 在「数据处理」输入源路径，或从 `datasets/raw/`、`datasets/rollouts/` 的候选项选择。相对路径以面板 `--root`／`VLA_ROOT`／启动目录为基准。
2. 打开后查看回合数、帧数、FPS 和视角数。回合列表每页 25 条，显示任务、结果、帧数与时长。
3. 点击「查看」，拖动时间轴、输入帧号或逐帧前进／后退。所有视角与数值使用同一原始帧时间；播放最高 10 Hz，暂停可精确检查每帧。缺帧／损坏视频显示错误，不以旧画面代替。
4. 勾选回合的「剔除」复选框，或恢复保留。成功／失败标签不触发自动筛选，必须人工决定。
5. 在左侧选择全局状态字段。默认全选，可按手臂／物理量成组或逐维选择；快捷预设仅显示源数据具备的字段。输出保持源字段顺序。「显示全部状态」只控制预览表格，不影响导出。
6. 确认输出路径。自动命名为 `datasets/sft/<源名称>_<维度>d`；手改路径后不随预设变化覆盖，可用「使用推荐路径」恢复。
7. 停止面板管理的真实硬件会话后点击「开始转换」。至少保留一个回合和一个状态字段，输出目录必须不存在，且不能与源目录相同或嵌套。
8. 查看后台进度；成功后「打开结果」再次预览。转换只输出新数据集，原始数据不变。

选择会自动保存。多标签页的冲突修改会拒绝并提示重新加载，不覆盖另一页面的草稿。源文件变化后须重新打开；重新打开将旧选择重置为全部保留，需再次确认。

## 后台任务与数据一致性

- 每个工作目录同时只允许一个转换任务。任务在独立进程中运行；关闭浏览器、关闭或重启 Web 服务不会结束它。重新打开数据处理页可关联原任务。
- 与同工作目录下的真实采集／部署会话互斥，启动检查使用同一把管理锁。可在硬件运行时预览其他已完成数据集。`--demo` 仅模拟设备，数据处理仍会读取本地文件并写入实际输出。
- 预览最多缓存 4 份元数据索引和 24 张缩略 JPEG，最多 4 个预览请求进入处理；显示尺寸不超过 640×480，不放大源图。慢请求丢弃迟到显示，切页停播。
- 转换持有源共享租约和输出独占租约，与遵守 WriterLease 的写入器互斥；检查源元数据内容、文件大小和修改时间。不要在外部工具中同时修改源文件，变更会导致转换拒绝发布。
- 逐回合处理数据和复制视频，不重新编码。重建连续 episode、全局 frame 和 task 索引；保留回合内 frame_index／timestamp。命令轨迹路径随输出更新。
- 按保留数据重算状态和有效动作统计，图像统计聚合保留回合；图像分位数沿用现有回合统计的加权近似规则。使用临时磁盘映射计算数值统计，逐列计算分位数。
- 输出完整解码检查视频帧数、尺寸及时间对应关系，成功后原子发布。取消在复制块、回合、统计列和视频校验之间生效，不中断写回原始数据，因为原始数据始终只读。
- 输出保留来源契约用于识别人工示范，旧在线运行身份和文件哈希转存来源记录；输出不能用来冒充或续写原在线运行。再次处理导出数据仍保留示范来源。
- 正常失败／取消清理临时输出，日志保留。进程被强制杀死时标记失败、不自动重跑；可能遗留输出父目录中的隐藏 `.名称.processing-*` 临时目录，确认任务退出后可手工清理，不能作为成功结果使用。

仅通过本地 API 返回已打开数据集中的帧与图像，不提供任意文件下载。沿用 Host／Origin 校验和写请求令牌。

## 文件与 CLI 重现

```text
runtime/web/processing/
  drafts/<dataset_id>.json          # 字段、保留回合、输出路径及草稿版本
  jobs/<job_id>/selection.json      # 提交时冻结的选择
  jobs/<job_id>/status.json         # 阶段、完成回合数或最终结果
  jobs/<job_id>/worker.log          # 后台错误与日志
  active.json                      # 进程身份与最近任务
```

导出数据中的 `meta/processing_selection.json` 保存原选择；`meta/info.json` 和 `meta/vla_metadata.json` 的 `processing` 字段保存源指纹、保留／剔除列表、回合／任务映射及来源契约。数据、运行目录和日志继续由 Git 忽略。

在同一工作目录可用命令重现选择，提供新的输出目录：

```bash
vla-extract-dataset-features \
  --source-root datasets/raw/原始数据集 \
  --selection-file runtime/web/processing/jobs/任务ID/selection.json \
  --output-root datasets/sft/新输出目录
```

`--selection-file` 与原 `--config` 二选一。选择文件 version=1，关键字段为 `source_fingerprint`、`state_fields` 和保留的 `episodes`；源指纹不符时拒绝执行。原 `--config` 提取行为继续保留。

更新安装包后先正常结束已有会话，再重启 Web 服务、刷新浏览器，新的导航页才会生效。
